# 🍏 Scripts Apple para Capture One

Scripts desarrollados para facilitar tu flujo de trabajo en Capture One: creación rápida de carpetas, reinicio del batch counter y más.


## 🚀 ¿Qué hacen estos scripts?

- Automatizan tareas comunes en Capture One para que no tengas que hacer todo a mano.  
- Funcionan directamente en tu Mac usando AppleScript.  


## 📂 Scripts incluidos

| Script                             | Qué hace                                       |
|------------------------------------|------------------------------------------------|
| `Folder_from_Txt.applescript`      | Crea carpetas a partir de un fichero `.txt`.   |
| `Folder_from_clipboard.applescript`| Crea carpetas a partir del portapapeles.       |
| `New_Folder.applescript`           | Crea carpetas para organizar tus vistas.       |
| `reset_batch_counter.applescript`  | Reinicia el contador de exportación (batch).   |


## 🧰 Requisitos

- macOS (obviamente 😄)  
- Capture One instalado (versión XX o superior)  

## ⚙️ ¿Cómo usarlos?

1. Descarga o clona este repositorio.  
2. Abre el script que quieras en el Editor de AppleScript o Automator.  
3. Ajusta lo que necesites (nombres, rutas, etc).  
4. Haz clic en “Run” y deja que los scripts hagan el trabajo por ti.
